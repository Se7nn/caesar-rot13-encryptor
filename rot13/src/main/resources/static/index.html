Cifrado ROT13 (Método e implementación)

1. ¿Qué es el Cifrado ROT13?

ROT13 (rotar 13 posiciones) es un caso particular del cifrado César, un algoritmo de sustitución monoalfabética desarrollado en la antigua Roma. Consiste en desplazar cada letra del alfabeto 13 posiciones hacia adelante o hacia atrás.

2. Propiedad de Involución (Simetría)

El alfabeto latino estándar tiene 26 letras. Dado que 13 + 13 = 26 (una vuelta completa al alfabeto), la función de cifrado y descifrado son exactamente la misma. Si aplicas ROT13 a un texto cifrado, recuperas automáticamente el texto original.

ABCDEFGHIJKLM
NOPQRSTUVWXYZ

3. Implementación Técnica

Esta aplicación web se comunica con un backend en Spring Boot:

  • Frontend: Captura el texto mediante un formulario HTML, lo envía por una petición HTTP POST usando JavaScript (fetch) y muestra el resultado dinámicamente.
  • Backend (Java): Recibe el JSON con el texto, itera sobre cada carácter evaluando si es una letra mayúscula o minúscula, aplica la fórmula aritmética modular (c - base + 13) % 26, y preserva intactos números, espacios y símbolos.
